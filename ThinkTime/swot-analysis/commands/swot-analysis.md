---
description: "Run a SWOT analysis with cross-quadrant strategy and prioritized recommendations"
argument-hint: "[product, business, or market position — text or file path]"
---

Invoke the `swot-analysis` skill and follow it exactly.

Arguments forwarded: `$ARGUMENTS`

The skill will:

1. Gather the available input (product state, competitive landscape, capabilities, market trends) and name what is missing.
2. Fill the four quadrants — 5–7 entries each for strengths, weaknesses, opportunities, threats.
3. Cross-reference the quadrants for SO / WO / ST / WT strategies.
4. Produce 3–5 prioritized recommendations with owners and tracking metrics.
