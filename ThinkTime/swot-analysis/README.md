# swot-analysis

Strategic assessment of a product, business, or competitive position: fills the
four SWOT quadrants, cross-references them into SO / WO / ST / WT strategies,
and closes with prioritized recommendations, owners, and tracking metrics.

- Skill: `skills/swot-analysis/SKILL.md`
- Command: `/ThinkTime:swot-analysis [product, business, or market position]`

Use `evaluate-proposal-harsh` instead when the goal is a go/no-go verdict on a
specific proposal document, and `idea-nebula` when the goal is generating new
ideas rather than assessing an existing position.
